# 心伴 Companion

AI 陪伴聊天網站。

## 功能

- ChatGPT API 回覆
- 輔導技巧升級版 system prompt
- WhatsApp 風格聊天介面
- 真人感慢回覆
- typing 動畫
- localStorage 儲存聊天紀錄
- 清除對話按鈕
- 深色模式
- 背景切換
- 心情快捷
- 呼吸練習
- SpeechSynthesis 語音朗讀

## 安裝

```bash
npm install
```

## 開發

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Vercel Deploy

在 Vercel 設定 Environment Variable：

```bash
OPENAI_API_KEY=你的APIKEY
```

然後 Deploy。

## 注意

此網站只作情緒陪伴及一般支援，不可取代專業心理治療、醫療服務或緊急服務。
